$ diff AGENTS.md.limpio AGENTS.md $ opencode # modelo open source > corrige el bug de expiración de token $ cat exfil/leaked.txt # ← nunca lo mencionó
Cambio a la terminal. Primero muestro el diff: una sola sección de diferencia entre el archivo limpio y el envenenado. Luego corro opencode con un modelo open source (DeepSeek o Qwen) y le pido corregir el bug. Observo que crea exfil/leaked.txt con el contenido del .env, y que en su resumen no lo menciona. Si el modelo en vivo no coopera, corro ./scripts/simular-ataque.sh. Punto a decir: con modelos open source obedece más fácil que con Claude; por eso son tan usados para esto.
