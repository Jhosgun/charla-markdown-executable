// EL PROBLEMA

El agente no distingue
datos de instrucciones.

Todo lo que lee —un README, un issue, un comentario, un AGENTS.md— puede convertirse en una orden que ejecuta.

El texto deja de ser documentación. Pasa a ser código.

Esta es la idea central. Un programa clásico solo ejecuta lo que está en el código. Un agente de IA ejecuta lo que entiende, y entiende texto. No hay una frontera dura entre "esto es un dato para leer" y "esto es una instrucción para obedecer". Guarda esa frase: el Markdown pasa a ser, de facto, un ejecutable.
