La defensa también es una skill: empaquétala y repártela. Probado en vivo con Claude.

Tercera demo: usar una skill. En .claude/skills/ del repo vive auditor-inyeccion, así que apenas alguien clona el repo y abre Claude Code, la skill está disponible. En vivo escribo: "usa la skill auditor-inyeccion para revisar repo-sospechoso". Claude carga la skill, corre scan.py y reveal.py, y da veredicto BLOQUEADO con la tabla de hallazgos — incluida la inyección OCULTA en CONTRIBUTING.md que un humano no ve. Mensaje: la defensa se empaqueta como skill y se reparte; cualquiera puede auditar un repo antes de darle permisos a su agente. Probado en vivo con claude -p. Enséñales el README con la lista de skills de seguridad/arquitectura/dev para que se lleven herramientas.
