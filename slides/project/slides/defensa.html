// LA DEFENSA

No le pidas permiso al modelo.
Intercepta la acción.

Hooks

Un PreToolUse inspecciona cada tool call y la bloquea si toca secretos, red o rutas de exfiltración.

Permisos

Allowlist/denylist: deny Read(.env), deny Bash(curl:*). Mínimo privilegio.

Sandbox

Sin red por defecto, FS acotado, arranca en la raíz del proyecto — no en Downloads.

Determinista: el AGENTS.md puede decir lo que sea; el hook no negocia.

La defensa no depende de que el modelo sea bueno. Tres capas. Hooks: un script que corre antes de cada acción y la puede vetar. Permisos: listas de denegación explícitas. Sandbox: el agente no tiene red ni acceso a secretos salvo lo necesario. La clave es que esto es determinista. El AGENTS.md envenenado sigue ahí; el hook lo bloquea igual. Esto responde directo al problema de opencode: no confías en que el modelo coopere.
