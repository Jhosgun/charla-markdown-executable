¿Qué es un AGENTS.md?

El archivo donde le dices al agente cómo trabajar en tu repo. Claude Code lo lee (y CLAUDE.md), igual Codex, opencode, Cursor, Gemini. Lo cargan antes de tocar el código.

proyecto/ ├── AGENTS.md # "cómo trabajar aquí" → el agente OBEDECE ├── CLAUDE.md ├── auth.js └── ...

La confianza es el bug: el agente asume que ese archivo es de buena fe.

AGENTS.md es un estándar de facto: un archivo Markdown en la raíz del repo con las convenciones del proyecto. Todos los agentes de código serios lo leen. El problema: lo leen y lo obedecen sin cuestionarlo, porque asumen que viene del dueño del repo. Pero ese archivo puede venir de una dependencia, de un repo que clonaste, de la carpeta Downloads. Ahí está la superficie de ataque.
